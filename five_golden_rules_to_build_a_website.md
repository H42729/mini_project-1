# 5 Golden Rules for Building a Great Website

Use these five rules as a simple checklist when building a website for a client, business, or personal project.

## 1. Know the Goal and the Audience

Before you write code, decide what the website should help visitors do. For example, a freelancer portfolio should show your work and help potential clients contact you.

**Ask yourself:**
- Who will use this website?
- What information do they need?
- What is the main action they should take?

## 2. Keep the Design Simple and Consistent

A website should be easy to understand. Use a small, consistent set of colors, fonts, spacing, and button styles. Avoid adding effects or sections that do not help the visitor.

**Remember:** Clear content is more important than decoration.

## 3. Make It Work on Every Screen

People may visit your website on phones, tablets, laptops, or desktop computers. Use a responsive layout and check the pages at different screen sizes. Make buttons and links easy to tap on mobile.

**Check:** Navigation, images, text, forms, and buttons should fit and work on small screens.

## 4. Prioritize Speed, Accessibility, and Security

Compress large images, avoid unnecessary scripts, and remove unused code to help pages load quickly. Use readable text, meaningful image descriptions, clear form labels, and keyboard-friendly navigation. Use HTTPS and never expose passwords, secret API keys, or private user data in frontend code.

**Remember:** A good website should be fast, usable by more people, and safe to use.

## 5. Test Before You Publish—and Keep Improving

Do not assume the website works just because it looks correct on your computer. Test every link, button, form, image, and important user flow. Check mobile layouts, loading speed, spelling, and common errors. After launch, listen to feedback and fix problems.

**Final checklist:**
- [ ] The website has a clear purpose.
- [ ] The design is consistent and easy to understand.
- [ ] It works on mobile and desktop.
- [ ] It loads reasonably quickly and follows basic accessibility and security practices.
- [ ] All important features have been tested.

---

**Golden principle:** Build for the person using the website—not just for the person writing the code.
